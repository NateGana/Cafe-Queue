# ☕ CafeQueue

A simple order board for a small café. Take orders from a menu and move them through a queue from New to Completed.

## Main Features
- Order board with four stages: New → Preparing → Ready → Completed
- Dashboard with today's orders, items in queue, ready orders and today's sales
- New Order form that builds the order from your menu and totals it automatically
- Move an order to the next stage with one click, or delete it
- Menu management: add, edit and delete items with category and price
- Search orders by table or order number
- Data saved in your browser with LocalStorage
- Responsive design with modal forms and toast messages

## Technologies
HTML5, CSS3, Vanilla JavaScript, LocalStorage

## How to Run
Open `index.html` in any modern browser. No install or server needed.
